This is the **Traditional Chinese (Hong Kong conventions)** tag taxonomy. It mirrors `vocabulary.md` term-for-term, so every tag here has a one-to-one counterpart in the simplified list.

## Language rule (hard rule)

- When output language is **繁體中文（港式）**, select tags **verbatim** from this file. Do not invent tags, do not mix with simplified forms, do not mix languages within one tag.
- The canonical spelling below is authoritative. Use it exactly as written (same casing, same characters).
- Hong Kong conventions apply: e.g. `手寫字體` (not 手寫體), `網頁UI` (not 網頁介面), `儀表板` (not 儀表盤), `資訊圖表` (not 信息圖表), `着陸頁` (not 落地頁).
