# Design Vocabulary (controlled tag taxonomy)

Use this as the tag taxonomy. Per asset keep only the most search-valuable tags (≈6–10 total across dimensions).

## Language rule (hard rule)

- **Tags are selected verbatim from this vocabulary — do not invent new tags.** If an asset genuinely needs a term not listed here, use the closest listed term rather than coining a one-off word.
- The canonical spelling below is authoritative. Use it exactly as written (same casing, same language). Do not translate, do not create synonyms, do not mix languages within one tag.
- **All tags are Chinese**, matching the Chinese names and annotations. There is no English tag anywhere in the taxonomy.
